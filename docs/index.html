The question

A support team wants to use AI to draft replies to order-status questions. Agents already use templates. You have two weeks to decide whether the AI feature deserves a wider rollout. What would you test, and what result would make you expand the pilot?

Take 30 seconds to answer out loud before opening the sample.

Read a sample answer
I’d start in one queue with AI-generated drafts that agents review before sending. I’d compare approved replies against the current templates and track time to send and factual corrections. I’d expand only if agents can send replies faster without making more factual mistakes.

This answer picks a baseline and a human approval step. Look for what an interviewer would still need to know to make a decision.
